# FullScreenClock
A simple, single-file full-screen clock.

To view it, visit [https://davidnmbond.github.com/FullScreenClock](https://davidnmbond.github.io/FullScreenClock/)

You can control the time and date formats as follows:

* https://davidnmbond.github.io/FullScreenClock/?timeFormat=HH:mm:ss&dateFormat=ccc+dd+LLL+yyyy
* https://davidnmbond.github.io/FullScreenClock/?timeFormat=HH:mm&dateFormat=yyyy-mm-dd
